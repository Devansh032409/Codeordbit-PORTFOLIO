A premium, modern, and fully responsive personal portfolio website built from scratch without the use of any heavy frameworks. Designed to showcase projects, skills, and professional experience with a sleek dark theme, glassmorphism UI, and smooth scroll animations.

---

## 🚀 Features

- **Dark Theme & Glassmorphism:** A professional, modern aesthetic featuring deep navy/charcoal backgrounds with vibrant neon blue and purple gradients.
- **Preloader Animation:** A custom spinning loader that seamlessly fades out when the page finishes loading.
- **Animated Typing Effect:** Dynamic hero section introduction using Vanilla JavaScript.
- **Scroll Reveal Animations:** Intersection Observer API used to fade and slide sections into view as the user scrolls.
- **Skill Progress Bars:** Animated progress bars that fill up dynamically upon scrolling into the viewport.
- **Fully Responsive:** Mobile-first approach using CSS Flexbox and Grid, ensuring perfect scaling on desktops, tablets, and mobile devices.
- **Sticky Navigation:** A modern sticky header with active section highlighting and a mobile hamburger menu.
- **Custom Scrollbar:** A styled WebKit scrollbar that matches the site's dark theme.
- **SEO Optimized:** Comprehensive meta tags, Open Graph tags, and semantic HTML for superior search engine visibility.

---

## 💻 Technologies Used

This project was built entirely with core web technologies to ensure maximum performance and zero dependency bloat:

* **HTML5:** Semantic structure and accessibility attributes.
* **CSS3:** Custom variables, Flexbox, Grid, keyframe animations, backdrop-filters (glassmorphism), and media queries.
* **Vanilla JavaScript (ES6+):** DOM manipulation, scroll event throttling, Intersection Observer, and typing logic.
* **FontAwesome:** For scalable vector icons.
* **Google Fonts:** Utilizing 'Inter' and 'Outfit' typography for a premium look.
